\# Лабораторна робота №4



\*\*Тема:\*\* Створення найпростішого HTTP-сервера на Node.js



\*\*Варіант:\*\* 7 — weather.json



\## Запуск



Встановити залежності:



`npm install`



Запустити сервер:



`node main.js -i weather.json -h 127.0.0.1 -p 3000`



\## Параметри запиту



\- `?humidity=true` — показати денну вологість.

\- `?min\_rainfall=10` — показати записи з кількістю опадів більше 10.

\- `?humidity=true\&min\_rainfall=10` — застосувати обидва параметри.



\## Збереження результату



`node main.js -i weather.json -h 127.0.0.1 -p 3000 -o result.json`



Сервер повертає результати у форматі JSON.
## HTTP-коди відповідей

- 200 OK — запит успішно виконано.
- 400 Bad Request — неправильний числовий параметр.
- 404 Not Found — запитано неіснуючий маршрут.
- 500 Internal Server Error — помилка читання або обробки файлу.

Після помилки сервер продовжує працювати.
